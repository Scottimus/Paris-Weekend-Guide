# Paris Weekend Guide

A bilingual mobile itinerary adapted from a family trip guide. The public edition uses a fictional schedule and public landmarks. [Try the live demo](https://scottimus.github.io/Paris-Weekend-Guide/) or open `index.html` locally to switch between English and Spanish, jump to a day, and open a landmark in Maps. The language choice persists locally when storage is available.

The guide uses plain HTML, CSS, and JavaScript. To check it after a change, switch to Spanish, use a day link, and reload. The same day and language should still be selected. The map links point to public landmarks.
